___
#### To run the program, make sure you are in the program's folder, then use the Run Command below.
___
##### Run Command:

`$ zig run -lc++ -cflags -std=c++23 -- if-else.cpp`

##### Results:

`7 is odd`
`8 is divisible by 4`
`9 has 1 digit`
___
#### C++ does have a ternary `?:` operator, unlike Go, though the `if` statement with an initializer (`if (int num = 9; ...)`) maps directly to Go's.
