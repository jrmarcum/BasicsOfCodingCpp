Go interfaces map to an abstract base class with pure virtual functions. Go's `fmt.Println(g)` prints a struct's fields as `{3 4}`, so each shape supplies a small `str()` method for that.
___
#### To run the program, make sure you are in the program's folder, then use the Run Command below.
___
##### Run Command:

`$ zig run -lc++ -cflags -std=c++23 -- interfaces.cpp`

##### Results:

`{3 4}`
`12`
`14`
`{5}`
`78.53981633974483`
`31.41592653589793`
