C++ has no XML in the standard library, so this lesson hand-writes a minimal encoder and a tag-scanning decoder for the `Plant` shape. Go's struct tags (`id,attr`, `parent>child>plant`) become explicit code.
___
#### To run the program, make sure you are in the program's folder, then use the Run Command below.
___
##### Run Command:

`$ zig run -lc++ -cflags -std=c++23 -- xml.cpp`
