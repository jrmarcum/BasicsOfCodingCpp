A `std::string` is a byte sequence like a Go string. A Go `rune` is a `char32_t`; the UTF-8 decoding done by Go's `range` and `utf8` package is written by hand (`decodeRune`, `runeCount`, `encodeRune`), and `fmtU` reproduces the `%#U` verb. Your terminal must be UTF-8 capable to display the Thai text.
___
#### To run the program, make sure you are in the program's folder, then use the Run Command below.
___
##### Run Command:

`$ zig run -lc++ -cflags -std=c++23 -- strings-and-runes.cpp`
